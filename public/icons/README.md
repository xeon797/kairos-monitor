# Kairos Monitor icons

Original DESIGN §9 rounded-square K artwork, rendered from SVG to PNG with locally installed Satoshi Bold using `node scripts/generate-icons.mjs`. Colors come from tokens.css. 192 and 512 px, purpose any (not maskable). The font is not embedded in these raster images. ITF FFL permits logos/images through normal font use; no font binary or font-bearing SVG is committed.
